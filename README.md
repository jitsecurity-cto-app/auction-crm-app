# Auction CRM App

Admin/backoffice Next.js application for managing the Vulnerable Auction Lab platform.

## Overview

This application provides admin functionality for managing auctions, users, orders, and disputes.

## Quick Start

```bash
npm install
npm run dev
```

The application will be available at `http://localhost:3002`
